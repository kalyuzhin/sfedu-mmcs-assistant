# Генеративный голосовой помощник

Данный проект представляет собой курсовую работу по разработке голосового помощника для кафедры МехМата ЮФУ. Система
объединяет модули распознавания речи, Retrieval‑Augmented Generation (RAG) на основе данных кафедры и
синтез речи. В основе лежит FastAPI‑бэкенд, обеспечивающий обработку аудиозапросов, формирование ответов и
их озвучивание в режиме реального времени. Также планируется добавить фронтенд для удобного взаимодействия с API.

## Цель работы

Цель данной курсовой работы — создать прототип голосового помощника, который позволит:

- **Автоматизировать** доступ к структурированной информации кафедры МехМата ЮФУ посредством семантического поиска по
  загруженной документации (Markdown, txt) в векторном хранилище.
- **Реализовать** модуль «речь → текст» для преобразования устных запросов пользователей в текстовые данные.
- **Интегрировать** Retrieval‑Augmented Generation (RAG) для извлечения и подбора релевантного контекста из
  академических материалов.
- **Обеспечить** синтез ответов в аудиоформате.

## Использование

### Требования

- **Python 3.12**
- **PortAudio** (для работы с аудио)
- **Git**
- **Docker & Docker Compose** (опционально, для контейнеризации)

### Локальная установка

1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/kalyuzhin/sfedu-mmcs-assistant.git
   cd sfedu-mmcs-assistant
   ```
2. **Настройка окружения**
   ```bash
   cp backend/.env-example backend/.env
   # Отредактируйте backend/.env, добавив API-ключи и другие параметры.
   ```
3. **Установка зависимостей**
   ```bash
   pip3.12 install -r backend/requirements.txt
   ```
4. **Запуск сервера**
   ```bash
   cd backend
   python main.py
   ```
   API будет доступен по адресу `http://localhost:8080`.

### Запуск в Docker

Сборка и запуск с помощью Docker Compose:

```bash
docker-compose up --build
```

Это запустит сервис `voice-assistant-mmcs-api` на порту `8080` по умолчанию.
